# ☕ F&A Coffee Menu - by Fadi Romany

**Live Demo:** https://fa-menu.vercel.app

![F&A Menu](https://fa-menu.vercel.app/og-image.jpg)

Modern, fast, and responsive digital menu for coffee shops with QR Code support. Scan and view the menu instantly.

### 🚀 Features
- 📱 Fully Responsive - Works on mobile & desktop
- ⚡ Built with Next.js 14 & Tailwind CSS
- 🔍 Category Filter
- QR Code Ready for tables

### 🛠 Tech Stack
- Next.js 14
- Tailwind CSS
- TypeScript
- Vercel Hosting
